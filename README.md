# Personal Finance Tracker

## 01 · Project Overview

A web application that allows users to manage their personal finances by recording **income and expense transactions**.

The application should be easy to use and designed for **students or anyone who wants to keep track of their daily spending**.

Users should be able to enter:

- Description
- Amount
- Transaction type (Income or Expense)
- Date

The application should display all transactions in a list and automatically calculate:

- Total income
- Total expenses
- Current balance

All data should be saved using the browser's `localStorage` so the information remains available after refreshing the page.

The interface should be responsive and work well on both desktop and mobile devices.
